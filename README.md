# Todo List Web App ✅

A simple task management web application built using HTML, CSS, and JavaScript.
This project was created to practice DOM manipulation, event handling, and basic front-end logic.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clear completed items
- Clean and responsive interface

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript

## How to Run
Open `index.html` in your web browser.
